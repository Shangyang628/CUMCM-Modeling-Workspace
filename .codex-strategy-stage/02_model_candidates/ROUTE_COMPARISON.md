# 四条建模路线比较

## 1. 前提核验

冻结规范已经给出明确目标、变量、约束、数据、时间范围、圆柱主判据、点目标 baseline 和区间并集口径，满足路线设计前提。本阶段比较的是模型结构与求解组织方式，不把外层优化器名称视为路线。

## 2. 四条路线的范式差异

| 路线 | 核心状态表示 | 遮蔽时间形成方式 | 协同决策结构 | 主要优势 | 主要短板 |
|---|---|---|---|---|---|
| A 透视解析事件 | 角域/支持函数与分段事件 | 解连续事件根并判定区间 | 外层直接作用于事件函数参数 | 连续时间精度高、数学表达强 | 分段推导复杂，Q5 扩展风险高 |
| B 自适应几何评价 | 圆柱可见表面与自适应单元 | 空间、时间双重自适应判定 | 连续参数直接调用评价器 | 稳妥通用、易复核 | 调用昂贵，若无误差证书容易模板化 |
| C 时空最大覆盖 | 有限候选动作与时间格覆盖向量 | 覆盖变量显式计并集 | 离散资源选择与覆盖约束 | 并集、弹数、间隔可显式表达 | 候选爆炸和离散误差 |
| D 可达域分层混合 | 遮蔽核、UAV 可达烟幕域和任务窗口 | 连续评价器复算区间 | 配对筛选→分配→连续精化→联合复算 | 最贴合 Q5 结构、解释与效率兼顾 | 需控制分层锁定和剪枝假阴性 |

## 3. 统一独立遮蔽时间评价器

四条路线必须共享一个物理语义固定的评价器。路线可以改变候选参数如何产生，但不能改变评价器对同一策略的判定。

### 3.1 接口契约

概念接口：

`Evaluate(strategy, physics_config, geometry_mode, tolerance_config) -> evaluation_record`

输入：

- 完整策略：UAV 航向/速度、各弹使用状态、投放时刻、引信延时、主指派导弹；
- 冻结物理配置：初始位置、速度、圆柱尺寸、烟幕参数、`g`；
- 几何模式：`cylinder_strict` 或 `center_baseline`；
- 容差配置：空间判定、时间端点、最大细分层级。

输出：

- 所有硬约束检查结果及物理不可行原因；
- 投放点、起爆点、起爆时刻和云团轨迹；
- 每个烟幕—导弹对的有效区间 `I_jik`；
- 每枚弹个体时长和每枚导弹区间并集 `C_j`；
- Q5 主指标 `C_1+C_2+C_3` 及替代聚合指标；
- 最小/最大几何裕度、边界残差、未认证区间；
- 评价配置、输入摘要哈希和诊断统计。

### 3.2 内部分层

1. **可行性门**：检查速度、共享航向速度、投放顺序、1 s 间隔、起爆高度和弹数。
2. **前向物理层**：只计算导弹、无人机、烟幕弹和云团轨迹。
3. **几何层**：独立实现点目标 baseline 与圆柱严格判据。
4. **连续时间层**：寻找所有真假切换边界，输出可多段的 `I_jik`。
5. **集合层**：对同一导弹做区间并集；任何上层模型都不能自行相加单弹时长。
6. **审计层**：输出容差、裕度和异常，而不是只给一个标量得分。

### 3.3 与优化器隔离

- 评价器不得读取迭代次数、候选来源或搜索历史。
- 相同输入和配置必须给出相同结果。
- 搜索阶段可使用较宽但固定的容差；最终候选必须使用严格容差重评。两种模式的物理和几何定义完全相同。
- 若无法在容差内判定边界，必须返回“未认证”，不能按有利方向取整。
- 缓存键只能由策略、物理配置、几何模式和容差构成。

### 3.4 验证矩阵

| 验证对象 | 最小测试 |
|---|---|
| 前向运动学 | Q1 的投放点 `(17620,0,1800)`、起爆时刻 `5.1 s`、符号起爆高度 `1800-6.48g` |
| 线段顺序 | 烟幕在线段上、导弹背后、目标之后三种场景 |
| 圆柱严格性 | 中心被遮但圆柱边缘未遮的反例 |
| 切触边界 | 球与极端目标视线恰切及微小内/外扰动 |
| 空间收敛 | 圆柱表面精度逐级提高，区间端点与时长趋稳 |
| 时间收敛 | 时间容差逐级减小，边界残差和并集时长趋稳 |
| 区间并集 | 重叠、相接、分离、空区间的确定性案例 |
| 交叉实现 | 路线 A 的事件结果与路线 B 的严格数值评价互核 |

## 4. 等权评分表

评分范围 1–5；5 表示更优。对 `Computational Cost`，5 表示成本低；对 `Optimization Difficulty`，5 表示难度低；对 `Homogenization Risk`，5 表示撞模风险低、题目特异性强。每项主观不确定性约 `±1`，总分只辅助导航，不能替代关键风险判断。

### 分数解释

- **A** 在数学精度、论文表达和题目特异性上强，但实现风险与 Q5 扩展性拖累整体。
- **B** 的问题覆盖最稳妥，适合作为备用和认证器；若缺少几何误差界，会退化为常见的采样黑箱。
- **C** 对区间并集、资源和指派最直观，适合作为组合层对照；连续精度依赖网格。
- **D** 同时利用圆柱遮蔽核、弹道可达域、共享航向和多目标任务结构，综合最强；它的得分依赖“安全筛选 + 多候选分配 + 最终严格复算”全部落实。

## 5. Q5 结构专项比较

| 方面 | 完全联合优化 | 任务分配 + 连续参数分层优化 |
|---|---|---|
| 决策空间 | 所有启用、指派、航向、速度、投放和延时一次决定 | 先配对/弹数/窗口，再在候选结构内决定连续参数 |
| 对全局耦合的表达 | 最完整 | 通过保留多个结构和最终联合精化近似保留 |
| 可解释性 | 低，失败原因难定位 | 高，可解释 UAV—导弹可达性和资源分配 |
| 计算与调试 | 混合维度高、非光滑、平台多 | 子问题规模较小，可分层验证 |
| 主要风险 | 搜索不足被误当作模型结论 | 早期分配或剪枝锁定错误结构 |
| 需要的证据 | 缩小规模上的重复稳定性和上界/对照 | 剪枝无假阴性、多候选保留、分层前后消融 |
| 建议角色 | 小规模对照与最后有限精化 | Q5 主结构 |

判断依据不是“分层方法常用”，而是本题存在强烈的题目特异结构：5×3 配对可达性差异、同一 UAV 多弹共享航向速度、导弹有效时间不同、目标函数按导弹分别做区间并集。

## 6. 简洁性关卡

| 组件 | 解决的独立问题 | 贡献证据/消融 | 结论 |
|---|---|---|---|
| 独立严格评价器 | 防止物理判据被搜索器污染 | Q1、人工场景、交叉实现与收敛 | 保留，必需 |
| 遮蔽核 `K_j(t)` | 表达圆柱完整遮蔽所需的球心区域 | 与直接圆柱射线判据逐时刻互核 | 保留 |
| UAV 可达烟幕域 `R_i(t)` | 排除物理不可达配对/窗口 | 被剪配对的上界或无交证书 | 保留 |
| 多候选任务分配 | 缓解单一分层结构锁定 | 保留数量敏感性、近优结构差距 | 保留 |
| 连续精化 | 修复网格或窗口原语的参数损失 | 精化前后目标与裕度差 | 保留 |
| 最终联合复算/精化 | 处理区间重叠和跨任务补偿 | 分层解与最终解差异 | 保留 |
| 无数据的学习型代理 | 仅减少调用，缺少可靠训练覆盖 | 无独立证据 | 当前拒绝 |
| 未经题面支持的复杂烟流 | 引入额外物理但无参数数据 | 无可验证数据 | 当前拒绝 |
| 仅更换外层搜索器 | 不解决新的建模问题 | 无结构消融 | 不构成路线或创新 |

## 7. 最小区分实验（规划，不执行）

用户选定路线后，正式实现的首个小规模实验应只回答路线风险，不追求最终最优值：

1. 用 Q1 固定策略比较 A 的事件评价与 B 的自适应评价，要求严格圆柱时长和边界在预设容差内一致。
2. 选取一组覆盖真、假、近切和点模型/圆柱模型分歧的 Q2 可行策略，检查评价器认证率与单次成本。
3. 在缩小的 Q4 场景上比较 C 的离散覆盖解与 D 的分层连续解，经统一评价器复算后比较时长、裕度和运行成本。
4. 对 Q5 只保留少量 UAV—导弹配对，比较完全联合与分层结构；若分层在统一复算下稳定达到联合结果且解释性明显更强，则支持 D，否则需扩大保留的任务结构。

本阶段没有运行这些实验。

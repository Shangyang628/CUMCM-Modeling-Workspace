## 2. 任务重述

来袭导弹沿固定直线飞向位于原点的假目标。无人机在 `t=0` 可瞬时改变航向，随后以选定的速度和航向保持等高度匀速直线飞行。烟幕弹投放后在重力作用下运动，通过时间引信在选定时刻起爆；起爆瞬间形成半径固定的球状烟幕云团，云团中心以固定速度竖直下沉，并在起爆后 20 s 内可能遮断导弹对真实圆柱目标的视线。问题 1 是固定策略的确定性评价；问题 2–5 是在不同无人机、烟幕弹和导弹规模下最大化有效遮蔽时间的连续时间耦合决策问题。

## 3. 坐标系与固定对象

### 3.1 坐标系

- 假目标为原点 `O=(0,0,0)`。
- `xy` 平面为水平面，`z` 轴竖直向上。
- 官方模板规定航向角：以 `+x` 轴为 `0°`，在 `xy` 平面内逆时针为正，取值 `0°–360°`。

### 3.2 假目标与真实目标

- 假目标位置：`O=(0,0,0)`。
- 真实目标是固定竖直圆柱，底面圆心 `B=(0,200,0)`，半径 `r_T=7 m`，高度 `h_T=10 m`。
- 真实目标的闭集合为

  `T = {(x,y,z): x^2+(y-200)^2 <= 7^2, 0 <= z <= 10}`。

- 几何中心为 `Q_c=(0,200,5)`。题面给出的 `(0,200,0)` 是底面圆心，不应在未说明时被当作整个目标的唯一代表点。

## 4. 统一运动学

### 4.1 导弹

三枚导弹速度均为 `v_M=300 m/s`，飞行方向始终从各自初始位置直指假目标原点。对导弹 `j`：

- 初始位置：`m_j^0`；
- 单位方向：`u_j = -m_j^0 / ||m_j^0||`；
- 轨迹：`m_j(t) = m_j^0 + 300 t u_j`；
- 有效时间域：`0 <= t <= T_j^hit = ||m_j^0||/300`。

对应到达假目标的时间约为：M1 `66.9992 s`，M2 `63.7504 s`，M3 `60.3665 s`。导弹不因烟幕而改变其题设轨迹；烟幕的作用只通过“遮蔽/未遮蔽”评价体现。

### 4.2 无人机

无人机 `i` 在 `t=0` 可瞬时调整到航向角 `theta_i`，随后航向和速度均不得再调整，并保持初始高度不变：

- `70 <= v_i <= 140`；
- `h_i=(cos theta_i, sin theta_i, 0)`；
- `d_i(t)=d_i^0+v_i t h_i`。

不同无人机的航向和速度可以不同；同一无人机投放多枚烟幕弹时，所有投放共享同一个 `theta_i` 和 `v_i`。

### 4.3 烟幕弹从投放到起爆

对无人机 `i` 的第 `k` 枚烟幕弹：投放时刻为 `t^d_ik`，引信延时为 `tau_ik>=0`，起爆时刻为 `t^e_ik=t^d_ik+tau_ik`。

题面只说明烟幕弹“脱离无人机后，在重力作用下运动”，没有给出空气阻力、风或弹体推进。为使问题闭合，暂定烟幕弹投放瞬间继承无人机的水平速度、竖直初速度为 0，只受重力：

`b_ik(t)=d_i(t^d_ik)+v_i(t-t^d_ik)h_i-(1/2)g(t-t^d_ik)^2 e_z`,

其中 `e_z=(0,0,1)`，`t^d_ik <= t <= t^e_ik`。

因此：

- 投放点 `p^d_ik=d_i(t^d_ik)`；
- 起爆点 `p^e_ik=d_i^0+v_i t^e_ik h_i-(1/2)g tau_ik^2 e_z`。

题面没有给出 `g` 的数值。后续计算的暂定值为 `g=9.8 m/s^2`，必须写入配置并对常用标准值 `9.80665 m/s^2` 做敏感性核验；不得把 `9.8` 伪称为题面数据。

### 4.4 起爆与烟幕云团

- 起爆方式：时间引信控制起爆时刻。
- 起爆瞬间形成球状烟幕云团。
- 有效半径：`R_S=10 m`。
- 云团中心下沉速度：`v_S=3 m/s`，方向为竖直向下。
- 有效寿命：起爆后 `L_S=20 s`。
- 云团中心：`c_ik(t)=p^e_ik-3(t-t^e_ik)e_z`，`t^e_ik <= t <= t^e_ik+20`。
- 云团几何：`S_ik(t)={x: ||x-c_ik(t)|| <= 10}`。

题面没有说明风致水平漂移、半径增长、浓度连续衰减或地面反射；统一规范按题面简化为固定半径、固定寿命和仅竖直下沉。球体落到地面以下的部分在几何上自然不与地上视线相交，不另行引入未经题面支持的反弹或贴地扩散。

## 5. “有效遮蔽”的严格定义

题面没有直接给出遮蔽判据。为避免把真实圆柱无声明地缩成一点，保留两个有明确层级的模型。

### 5.1 A：目标中心点近似模型（baseline）

用真实目标几何中心 `Q_c=(0,200,5)` 表示目标。若有效期内烟幕球与导弹位置 `m_j(t)` 到 `Q_c` 的闭线段相交，则判为遮蔽：

`E^A_jik(t)=1` 当且仅当 `t` 在烟幕有效期和导弹飞行期内，且

`dist(c_ik(t), [m_j(t),Q_c]) <= 10`。

这里必须使用线段距离而不是无限直线距离，从而排除位于导弹背后或目标之后、但碰巧靠近同一直线的云团。

该模型只保证目标中心方向的单条视线被截断，不保证圆柱边缘、顶面或侧面均被遮住，因此通常偏乐观。它适合做公式检查、快速 baseline 和高保真结果的偏差对照，不适合作为最终主判据。

### 5.2 B：真实圆柱可见轮廓完全遮蔽模型（主模型）

对任一时刻的导弹位置 `m=m_j(t)`，定义圆柱的可见表面

`V(m)={q in boundary(T): 开线段 (m,q) 不穿过圆柱内部}`。

对每个可见点 `q`，其视线段为 `[m,q]`。定义烟幕中心对全部可见视线段的最坏距离：

`Delta_jik(t)=sup_{q in V(m_j(t))} dist(c_ik(t), [m_j(t),q])`。

严格有效遮蔽判据为：

`E^B_jik(t)=1` 当且仅当

1. `t^e_ik <= t <= t^e_ik+20`；
2. `0 <= t <= T_j^hit`；
3. `Delta_jik(t) <= 10`。

数学含义是：从导弹观察点出发，指向真实圆柱全部可见轮廓的每一条视线，在到达目标前都与烟幕球相交；等价地，烟幕球在导弹视角下的投影视域完全覆盖真实圆柱的透视轮廓。该定义保留半径 7 m、高 10 m 的真实几何范围，且自动保证烟幕处在导弹与相应目标点之间。

### 5.3 两种判据比较

| 方面 | A：中心点近似 | B：圆柱完全遮蔽 |
|---|---|---|
| 目标表示 | 单点 `(0,200,5)` | 半径 7 m、高 10 m 的可见圆柱轮廓 |
| 判定含义 | 一条中心视线被烟幕球截断 | 所有可见目标视线均被烟幕球截断 |
| 单时刻计算量 | 常数级线段距离 | 连续表面最坏值；离散核验时随表面点数增长 |
| 误差倾向 | 易高估遮蔽时长 | 保守且更贴近“对真目标提供遮蔽” |
| 用途 | baseline、调试、消融对照 | 主模型与最终结论依据 |
| 本题合理性 | 可作为远距离、小目标近似，但目标尺寸与烟幕半径同量级，不能无检验替代圆柱 | 与题目明确给出的圆柱尺寸一致，题意符合度更高 |

结论：B 为主模型；A 仅为 baseline。后续策略设计需要讨论 B 的连续几何核验精度及误差界，但本阶段不选择实现方法。

## 6. 多枚烟幕的时间聚合

对导弹 `j` 和烟幕弹 `(i,k)`，令

`I_jik={t: E_jik(t)=1}`。

同一导弹的总有效遮蔽时间必须是时间区间并集的测度：

`C_j = measure(union_(i,k) I_jik) = integral 1{max_(i,k) E_jik(t)=1} dt`。

不同烟幕弹造成的重叠时段只计一次；`measure(I_1)+measure(I_2)` 只有在两区间不重叠时才等于并集长度。题面允许不同烟幕弹的遮蔽不连续，因此 `I_jik` 和总并集都允许由多个不连续区间组成。

对问题 5，工作目标定义为无权威差异时的“威胁-秒”总量：

`C_total=C_1+C_2+C_3`。

同一导弹上的重叠不重复计数；不同导弹是不同威胁通道，因此同时被遮蔽的时段可分别计入各自 `C_j`。题面未明确跨导弹聚合口径，后续必须同时报告 `C_1,C_2,C_3`，并把“全局日历时间并集”作为口径敏感性对照，而不能隐藏这一解释。

## 8. 问题 1 的固定状态核验

FY1 朝假目标方向飞行，因此 `theta_1=180°`，速度 `120 m/s`；`t^d=1.5 s`，`tau=3.6 s`，`t^e=5.1 s`。

- 投放点：`(17620,0,1800)`。
- 起爆点：`(17188,0,1800-6.48g)`。
- 若采用暂定 `g=9.8`，起爆点为 `(17188,0,1736.496)`。
- 烟幕有效候选时间窗：`[5.1,25.1] s`，还必须与 M1 飞行期及实际遮蔽判据的成立时段求交。

本节只是对题面固定量的代数核验，不计算最终遮蔽时长。

# Method–Result Boundary

## Methodology

Include definitions, formulas, assumptions, feature/sample construction, objective and constraints, solver/training protocol, validation design, predeclared thresholds, lookback/horizon, and artifacts the method will produce.

## Solution/results

Reserve observed metrics, fitted parameter estimates when reported as outcomes, selected-model rankings, predictions, category counts, figure patterns, sensitivity responses, and performance claims for the solution chapter.

When a number could be either, ask whether it was fixed before execution. If yes, describe it as a design constant and cite configuration/code. If it was learned, measured, or selected from results, keep it out of methodology.

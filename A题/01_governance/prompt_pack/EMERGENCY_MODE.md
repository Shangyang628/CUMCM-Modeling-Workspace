# A题专用 Prompt：时间紧张模式

```text
$math-modeling-orchestrator

剩余时间：【待填写小时数或截止时间】。若仍为UNKNOWN，不启动应急排程，先请求用户补充。

目标是完整、可信、可复现地回答4问并提交result1–4.xlsx与论文。保留不可取消Gate：题意/边界定义冻结；公共baseline与oracle；Q1–Q4最终答案独立重算（Q3/Q4阈值前后、Q4移动域守恒）；Excel回读；论文—代码—图表—工作簿一致性。

压缩方式：路线只比较2–3条；优先统一的一维径向固定/移动域框架但必须由路线Gate决定；Q1先验证公共核心，Q2复用，Q3只增加长时阈值事件，Q4最后增加移动边界；敏感性只保留Δr/Δt、长时环境边界、R(t)插值三类主风险；非关键图表延后。复杂方案若未在预算内超过经验证baseline或守恒失败，立即回退。

输出按实际剩余时间分为 MUST/SHOULD/IF TIME/DROP，并给每阶段绝对截止、最小工件、回退触发、负责人UNKNOWN占位。最后指定下一条Prompt并停止，不直接求解。
```

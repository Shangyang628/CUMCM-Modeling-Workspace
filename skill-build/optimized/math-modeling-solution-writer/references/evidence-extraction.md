# Evidence Extraction

1. Identify final run ID and authoritative artifacts.
2. Read methodology for names, symbols, units, and promised outputs.
3. Read final code/configuration to understand how sheets, keys, figures, and metrics were produced.
4. Inspect every relevant workbook sheet, CSV/JSON key, log, and final figure.
5. Extract only claims needed to answer the problem; record source path and locator.
6. Check population, split, date convention, units, denominators, rounding, and missingness.
7. Compare table and figure claims before drafting.

Recommended evidence-ledger fields: claim ID, prose claim, value, unit, artifact path, sheet/key/figure, row or condition, run ID, and verification status.

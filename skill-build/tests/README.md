# Test Scope

`trigger-cases.yaml` contains positive, negative, and boundary cases for all installed skills, including the six requested smoke-test phrasings. `modeling-route-cases.md` contains five anti-template modeling scenarios.

Static validation checks metadata, unique names, local references, unsafe path/execution patterns, and required behavioral clauses. Runtime Codex discovery must be rechecked in a newly started or refreshed task after installation; it is not inferred from static files.

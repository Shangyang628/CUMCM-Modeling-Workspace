## 3. 决策变量、状态变量和派生变量

### 3.1 无人机层

| 符号 | 类型 | 含义 | 约束 |
|---|---|---|---|
| `theta_i` | 决策/控制 | 无人机航向角 | `0 <= theta_i < 2pi`；确定后不变 |
| `v_i` | 决策/控制 | 无人机飞行速度 | `70 <= v_i <= 140`；确定后不变 |
| `d_i(t)` | 状态 | 无人机位置 | `d_i^0+v_i t(cos theta_i,sin theta_i,0)` |

### 3.2 烟幕弹层

| 符号 | 类型 | 含义 | 约束/关系 |
|---|---|---|---|
| `y_ik` | 离散决策 | 第 `k` 枚弹是否使用 | Q1–Q4 由题目固定；Q5 为 0/1 |
| `t^d_ik` | 连续决策 | 投放时刻 | `t^d_ik >= 0` |
| `tau_ik` | 连续决策 | 引信延时 | `tau_ik >= 0` |
| `t^e_ik` | 派生 | 起爆时刻 | `t^e_ik=t^d_ik+tau_ik` |
| `p^d_ik` | 派生 | 投放点 | `d_i(t^d_ik)` |
| `p^e_ik` | 派生 | 起爆点 | 由无人机运动与抛体运动唯一决定 |
| `c_ik(t)` | 状态 | 起爆后云团中心 | `p^e_ik-3(t-t^e_ik)e_z` |
| `a_ikj` | 离散决策 | Q5 中该弹主指派给导弹 `j` | 0/1，且 `sum_j a_ikj=y_ik` |

投放点和起爆点不是可与 `theta_i,v_i,t^d_ik,tau_ik` 独立任意选择的自由变量；它们必须满足运动学等式。否则会产生物理不可执行的“策略”。

### 3.3 导弹与遮蔽层

| 符号 | 类型 | 含义 |
|---|---|---|
| `m_j(t)` | 外生状态 | 导弹固定轨迹位置 |
| `T_j^hit` | 派生参数 | 导弹到达假目标的时间 |
| `E_jik(t)` | 派生二值状态 | 选定几何判据下是否有效遮蔽 |
| `I_jik` | 派生集合 | `{t:E_jik(t)=1}` |
| `C_j` | 结果指标 | `measure(union_(i,k) I_jik)` |
| `C_total` | Q5 目标指标 | `C_1+C_2+C_3` |

## 4. 通用硬约束

1. **速度约束**：`70 <= v_i <= 140`。
2. **等高直线约束**：无人机的 `z` 坐标恒为初始高度；在 `t=0` 后不得改变航向或速度。
3. **投放非负时间**：`t^d_ik >= 0`。
4. **因果顺序**：`t^e_ik=t^d_ik+tau_ik` 且 `tau_ik>=0`。
5. **弹道约束**：投放点、起爆点必须由统一运动方程产生。
6. **起爆可行性**：`p^e_ik,z >= 0`，等价于 `tau_ik <= sqrt(2 z_i^0/g)`；不允许在地面以下起爆。
7. **有效窗口**：烟幕只能在 `[t^e_ik,t^e_ik+20]` 内贡献遮蔽，并与导弹飞行区间 `[0,T_j^hit]` 求交。
8. **同机间隔**：若同一无人机按编号依次使用两枚弹，则 `t^d_i,k+1-t^d_ik >= 1`。
9. **数量约束**：Q3 的 FY1 恰投 3 枚；Q4 的 FY1–FY3 各恰投 1 枚；Q5 每架至多 3 枚。
10. **几何约束**：主结果采用圆柱完全遮蔽判据；中心点模型只能作为 baseline 单列。
11. **并集计时**：同一导弹上多枚烟幕的重叠区间不得重复计时。

`t^e_ik <= T_j^hit` 可作为无损的相关时间域限制：在目标导弹已经到达假目标之后起爆不会增加目标值。Q5 中若一枚弹被指派给 `j`，则对该弹使用相应 `T_j^hit`。

## 5. 各问决策变量、目标与约束

### Q1：固定策略评价

- 固定：`i=1,j=1,k=1`，`theta_1=pi`，`v_1=120`，`t^d=1.5`，`tau=3.6`。
- 自由决策变量：无。
- 目标/输出：计算 `C_1=measure(I_111)`，同时输出遮蔽区间端点以便审计。
- 必须分别计算主模型 B 和 baseline A，不得只报点模型。

### Q2：FY1 单弹对 M1

- 决策向量：`(theta_1,v_1,t^d_11,tau_11)`。
- 派生输出：`p^d_11,p^e_11,t^e_11`。
- 目标：`max C_1`。
- 约束：全部通用约束；使用 1 枚弹；只有一个无人机航向和速度。

### Q3：FY1 三弹对 M1

- 共享决策：`theta_1,v_1`。
- 每弹决策：`(t^d_1k,tau_1k), k=1,2,3`。
- 数量：`y_11=y_12=y_13=1`。
- 投放顺序：可按时间重新编号，使 `t^d_11<t^d_12<t^d_13`；并有 `t^d_12-t^d_11>=1`、`t^d_13-t^d_12>=1`。
- 目标：`max measure(I_111 union I_112 union I_113)`。
- 禁止目标：`measure(I_111)+measure(I_112)+measure(I_113)`，除非已证明区间两两不重叠。

### Q4：FY1、FY2、FY3 各一弹对 M1

- 对 `i=1,2,3`，决策 `(theta_i,v_i,t^d_i1,tau_i1)`。
- 每机恰投 1 枚，因此同机最小间隔约束不激活。
- 目标：`max measure(I_111 union I_211 union I_311)`。
- 不同无人机可以有不同航向和速度。

### Q5：五机至多三弹对 M1、M2、M3

- 对每架无人机决策共享的 `(theta_i,v_i)`。
- 对每个候选弹位决策 `y_ik,t^d_ik,tau_ik`。
- 对每个使用的烟幕弹决策主指派 `a_ikj`，满足 `sum_j a_ikj=y_ik`。
- 每机数量：`sum_k y_ik<=3`。
- 同机已使用弹按时间编号并满足相邻投放至少 1 s。
- 三个威胁均须被实质干扰：工作规范要求 `C_j>0`，`j=1,2,3`；若策略阶段认为仅要求“分配至少一枚弹”更符合题意，必须同时报告对应差异。
- 目标：`max C_total=max(C_1+C_2+C_3)`，其中每个 `C_j` 都先对该导弹的烟幕区间取并集。
- 一个云团可能偶然同时遮蔽多条视线；官方模板只提供一个“干扰的导弹编号”字段，因此主指派标签唯一，但验证阶段应记录附带遮蔽，避免物理效果丢失。

## 6. 官方模板字段约束

### `result1.xlsx`（Q3）

- 单表 `Sheet1`，范围 `A1:J6`，预置 3 枚弹编号。
- 列：无人机运动方向、无人机运动速度、烟幕弹编号、投放点 `x/y/z`、起爆点 `x/y/z`、有效干扰时长。
- 备注：航向角以 `+x` 轴为正向，逆时针为正，`0–360°`。

### `result2.xlsx`（Q4）

- 单表 `Sheet1`，范围 `A1:J6`，预置 FY1、FY2、FY3。
- 列：无人机编号、运动方向、运动速度、投放点 `x/y/z`、起爆点 `x/y/z`、有效干扰时长。

### `result3.xlsx`（Q5）

- 单表 `Sheet1`，范围 `A1:L18`，为 FY1–FY5 各预置 3 行，共 15 个弹位。
- 列：无人机编号、运动方向、运动速度、烟幕弹编号、投放点 `x/y/z`、起爆点 `x/y/z`、有效干扰时长、干扰的导弹编号。

三个模板都没有投放时刻和起爆时刻列。因此完整策略必须在独立结果表、日志或论文中保留这些时刻；不得因为模板没列就丢失可复现参数。模板的逐行“有效干扰时长”应记录单枚弹的个体时长，优化目标与最终总时长则必须另按区间并集计算并报告。

## 7. 未提供、因而不得私自增加的约束

- 无人机之间或无人机与导弹之间的避碰距离。
- 无人机飞行区域边界或最大航程。
- 烟幕弹投放后的空气阻力、风场和水平漂移。
- 不同无人机之间的同步误差。
- 导弹看到烟幕后改变航向或速度的制导反馈。
- 不同导弹或烟幕弹的优先级权重。

这些内容只能在后续作为扩展或稳健性情景，不能伪装成原题硬约束。

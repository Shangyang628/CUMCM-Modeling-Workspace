# Nature Writing

Develop clear scientific arguments from the user's actual evidence. “Nature” describes disciplined scientific communication, not permission to imitate a journal or exaggerate novelty.

## Intake

Identify section, audience, language, claim, evidence, boundaries, and output format. If essential evidence is missing, use an explicit placeholder or list the missing input rather than inventing content.

## Drafting

1. Write a one-sentence section argument.
2. Map each claim to evidence and its limitation.
3. Order paragraphs by reasoning rather than file order.
4. Draft with concrete subjects, restrained verbs, defined terminology, and transitions that reflect the logic.
5. Check that every result claim has evidence and every limitation is preserved.

For mathematical-modeling “模型的建立” or “模型的求解” requests, defer to the dedicated modeling writer because those skills enforce the code/result boundary.

## Fidelity Rules

- Do not create data, experiments, metrics, citations, causal claims, or novelty claims.
- Preserve formulas, variables, units, parameters, uncertainty, and negative results.
- Keep methods separate from empirical results unless the requested venue combines them.
- State assumptions and missing evidence explicitly.
- Avoid promotional phrasing and generic significance claims.

## Output

Return the requested section and a short list of assumptions or missing evidence when present. Do not add a fabricated bibliography or claim journal compliance without checking the journal's current instructions.
